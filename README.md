# 🎮 Turbomachinery Python Games & Simulators
### ألعاب بايثون التفاعلية لمحاكاة وتشخيص التوربينات ومحطات الطاقة

[![Dependencies](https://img.shields.io/badge/Dependencies-Zero%20External%20Pip-orange.svg)]()

[![Author: Mohammed Basra](https://img.shields.io/badge/Author-Mohammed%20Basra-181717.svg)](https://github.com/mohammedbasra-star)

مجموعة ألعاب محاكاة هندسية تفاعلية ممتعة ومبرمجة بالكامل بلغة **بايثون (Pure Python)** مع واجهات رسومية لسطح المكتب (**Tkinter GUI**) وواجهات سطر أوامر تفاعلية (**CLI**). صُممت لدمج متعة تعلم البرمجة مع فهم فيزياء وتشغيل الآلات الدوارة، التحكم في المحطات، وتشخيص أعطال الاهتزازات.

---

## 🌟 مميزات الألعاب (Key Features)

- **صفر متطلبات خارجية (Zero External Dependencies):** تعمل مباشرة بمكتبة بايثون القياسية دون الحاجة لتثبيت أي حزم عبر `pip`.
- **واجهات رسومية عربية حديثة (Native Arabic GUI):** خطوط عربية واضحة بنسبة 100% ومصممة بألوان واضحة وأشرطة مؤشرات حية (Gauges).
- **تشغيل بنقرة واحدة (One-Click Launch):** ملفات تشغيل سريعة (`.bat`) لنظام ويندوز تفتح الألعاب فوراً.
- **فيزياء هندسية حقيقية:** محاكاة حقيقية لدورات برايتون، رانكن، حرارة العادم EGT، اهتزازات المحامل، وظاهرة الرنين والـ Trip.

---

## 🕹️ الألعاب المتضمنة في المستودع

### 1️⃣ لعبة مشغّل غرفة التحكم (Turbine Control Room Operator)
* **الملف الرسومي:** `gui_game_01_control_room.py` (أو النسخة الطرفية `game_01_control_room.py`)
* **ملف التشغيل السريع:** `play_gui_game_01.bat`
* **المهمة:** أنت مهندس التشغيل في محطة كهرباء شط البصرة؛ شبكة الكهرباء تطلب ميجاواط (MW) متغيرة في ظل صيف حار. اضبط صمام الوقود ونظام رذاذ تبريد هواء السحب (Fogging) لتوليد الطاقة المطلوبة مع تجنب حدوث إيقاف اضطراري (**TRIP**) إذا تجاوزت حرارة العادم 650°C أو الاهتزازات 9.0 mm/s.

---

### 2️⃣ لعبة المحقق الهندسي للأعطال (Diagnostic Detective)
* **الملف الرسومي:** `gui_game_02_detective.py` (أو النسخة الطرفية `game_02_diagnostic_detective.py`)
* **ملف التشغيل السريع:** `play_gui_game_02.bat`
* **المهمة:** حل 3 قضايا أعطال غامضة طارئة في محطات الرميلة، شط البصرة، والهارثة. استهلك ميزانية ساعات الفحص لطلب تحاليل مخبرية (طيف الاهتزازات FFT 1X/2X، فحص عينات الزيت، كاميرا البورسكوب، وانتظام الاحتراق) لتحديد السبب الجذري بدقة وإنقاذ التوربينة قبل تحطمها.

---

### 3️⃣ لعبة مهندس الدورة المركبة الكبرى (Combined Cycle CCGT Master)
* **الملف الرسومي:** `gui_game_03_ccgt.py` (أو النسخة الطرفية `game_03_combined_cycle_ccgt.py`)
* **ملف التشغيل السريع:** `play_gui_game_03.bat`
* **المهمة:** صمم ووازن محطة طاقة هجينة فائقة التطور (توربينة غازية + مرجل استعادة الحرارة HRSG + توربينة بخارية). حرّك المؤشرات التفاعلية لنسبة الانضغاط، حرارة الاحتراق، وضغط البخار لكسر **حاجز كفاءة الـ 60%** العالمية وتحقيق أقصى أرباح تجارية في الساعة.

## 🚀 طريقة التثبيت والتشغيل السريع

### 1. استنساخ المستودع (Clone)
```bash
git clone https://github.com/mohammedbasra-star/game.git
cd game
```

### 2. تشغيل مركز الألعاب الموحد (Games Hub)
يمكنك فتح مركز الألعاب الرئيسي واختيار أي لعبة تريدها:

* **عبر بايثون:**
  ```bash
  python turbine_games_hub.py
  ```
* **أو على نظام ويندوز بنقرة واحدة:**
  فقط اضغط مرتين على ملف **`play_games_hub.bat`**.

## 📚 دروس تعليم بايثون المرفقة (Beginner Lessons)
يحتوي المستودع أيضاً على دروس تأسيسية مصممة خطوة بخطوة باللغة العربية:
* `lesson_01.py`: المتغيرات، أنواع البيانات، والطباعة والإدخال.
* `lesson_02.py`: العمليات الحسابية، الأسس، وتحويل البيانات.
* `lesson_03.py`: الشروط البرمجية واتخاذ القرارات (`if / elif / else`).
